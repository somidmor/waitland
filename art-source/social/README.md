# Social artwork source

`waitland-og-background.png` is the unscaled ImageGen master for the production
Open Graph image at `public/og.png`. It uses the same rounded miniature people,
golden meadow, central pit, and distant guardian as the application redesign.

The runtime image is intentionally resized to the metadata-declared 1200 × 630
pixels. No text is baked into the artwork; platforms render the page title and
description alongside it, and the scene remains legible at small card sizes.
